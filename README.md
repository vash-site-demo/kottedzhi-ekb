# Дома у Екатеринбурга

Демонстрационный одностраничный сайт-каталог посуточной аренды загородных домов. Проект создан для портфолио: это не действующий сервис и не клиентская работа.

## Возможности

- 16 карточек вымышленных домов с фотогалереями;
- фильтры по датам, числу гостей, категории и удобствам;
- логика «ИЛИ» внутри категорий и «И» для выбранных удобств;
- понятное пустое состояние: сайт объясняет, если подходящие дома заняты на выбранные даты, и позволяет убрать только даты;
- сортировка по цене и вместимости;
- интерактивная карта с условными метками;
- форма заявки с именем, телефоном, домом, датами, числом ночей и гостей;
- журнал заявок со всеми удобствами дома и выбранными фильтрами;
- выгрузка журнала в CSV с кодировкой UTF-8 BOM для открытия в Excel;
- формирование и копирование текста обращения без имитации отправки;
- адаптивная версия, мобильное меню и доступное управление с клавиатурой.

## Хранение заявок

Заявки сохраняются в `localStorage` текущего браузера. Они не передаются владельцу, не синхронизируются между устройствами и исчезнут при очистке данных браузера. Кнопка «Скачать CSV для Excel» формирует файл со всеми сохранёнными записями. Пользовательские поля защищены от интерпретации как формул Excel.

Для реального приёма обращений потребуется подключить отправку на сервер, в Telegram, на почту или в CRM. В статическом демо такая доставка намеренно не имитируется.

## Стек

Семантический HTML, CSS и JavaScript без сборки приложения. Vite используется только для локального предпросмотра. Карта — Leaflet и OpenStreetMap, иконки — Lucide. Данные каталога лежат в `data/houses.json`.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для проверки логики фильтров:

```bash
npm test
```

Браузерная проверка выполняется при запущенном локальном сервере на порту 7100:

```bash
npm run dev -- --port 7100
npm run test:browser
```

Проверяются фильтры, занятые даты, формы, сохранение заявки после перезагрузки, CSV, карта, галереи, навигация и адаптивность.

## Публикация на GitHub Pages

Проект статический. После загрузки репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и корневую папку `/ (root)`. Все пути относительные, поэтому сайт работает и в подпапке GitHub Pages.

## Ограничения демо

Все дома, изображения, цены, занятость и расположение вымышлены. Бронирование, оплата и внешняя отправка заявок не подключены. Для реального запуска нужны данные владельца, источник занятости и канал приёма обращений.
